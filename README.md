Desenvolvimento criativo é o meio do caminho entre engenharia e design, e é exatamente ali que eu trabalho.
Construo interfaces com personalidade, movimento e ritmo, apoiadas em arquitetura que aguenta produção:
React, Next.js, TypeScript e Node.js na base, PostgreSQL guardando o estado, AWS e CI/CD entregando.

Gosto de projeto que exige as duas cabeças no mesmo dia: decidir o contrato da API de manhã e a curva da
animação à tarde. Marca, interface e código tratados como uma coisa só, porque para quem usa eles são.
